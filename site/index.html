How to read the leaderboard

Primary metric

MRR measures how highly the correct root-cause service appears in each predicted ranking. Higher is better.

Ranking accuracy

Top@k is the share of cases where the correct service appears within the first k predictions.

Reproducibility

Published runs use immutable containers and dataset revisions. The Run link opens the archived metrics.
